# سند طراحی محصول: اپ یادگیری لغت انگلیسی (آفلاین)

> نسخه‌ی ۱ · پیش‌نویس برای تأیید · ۳۱ اکتبر ۲۰۲۶

---

## ۱. خلاصه‌ی محصول

یک اپ اندرویدی کاملاً آفلاین برای یادگیری لغت انگلیسی از سطح **Elementary تا Advanced**.
لغت‌ها فصل‌به‌فصل آموزش داده می‌شن، با تمرین‌های متنوع جا می‌افتن، با آزمون سنجیده می‌شن و با **مرور هوشمند (Spaced Repetition)** در حافظه‌ی بلندمدت می‌مونن.

| ویژگی | توضیح |
|---|---|
| بدون سرور | همه‌ی داده‌ها روی گوشی ذخیره می‌شن |
| بدون اینترنت | تلفظ هم با موتور TTS خود اندروید کار می‌کنه |
| انتقال پیشرفت | با Export/Import یک فایل پشتیبان |
| زبان رابط | فارسی (راست‌به‌چپ)، با محتوای انگلیسی |

### هدف کاربر
«می‌خوام هر روز چند دقیقه تمرین کنم، مرحله‌به‌مرحله جلو برم، بدونم کجام و چیزهایی که یاد گرفتم یادم نره.»

### معیار موفقیت محصول
- کاربر هر روز برمی‌گرده (Streak)
- درصد تسلط فصل‌ها با گذشت زمان بالا می‌ره، نه پایین
- لغت‌های یادگرفته‌شده بعد از یک ماه هنوز یادش هست

---

## ۲. اصول یادگیری (پایه‌ی علمی طراحی)

| اصل | توی اپ چطوری پیاده می‌شه |
|---|---|
| **تکرار با فاصله** | هر لغت درست قبل از فراموش شدن دوباره نشون داده می‌شه (الگوریتم FSRS) |
| **یادآوری فعال** | توی تمرین‌ها اول جواب می‌دید، بعد جواب درست رو می‌بینید |
| **تولید به‌جای تشخیص** | تمرین‌ها به‌ترتیب سخت‌تر می‌شن: انتخاب ← وصل کردن ← تایپ |
| **یادگیری در بافت** | هر لغت با جمله‌ی مثال و Collocation آموزش داده می‌شه |
| **کدگذاری دوگانه** | تلفظ صوتی + تمرین شنیداری |
| **ترکیب تمرین‌ها** | مرور روزانه لغت‌های همه‌ی فصل‌ها رو قاطی می‌کنه |
| **عادت روزانه** | Streak، هدف روزانه و یادآوری |

## ۳. ساختار محتوا

```
سطح (Level)
 └── فصل (Unit)
      ├── لغت‌ها (Words)
      ├── تمرین‌ها (Exercises)
      └── آزمون فصل (Unit Test)
 └── آزمون سطح (Level Test)
```

### سطح‌ها
1. Elementary
2. Pre-intermediate
3. Intermediate
4. Upper-intermediate
5. Advanced

### اطلاعات هر لغت

| فیلد | مثال | اجباری؟ |
|---|---|---|
| کلمه | `siblings` | بله |
| معنی فارسی | خواهر و برادر | بله |
| نوع کلمه | noun (plural) | خیر |
| جمله‌ی مثال | Arash and Nazanin are siblings. | بله |
| نکته | برای دختر و پسر یکسانه | خیر |
| خانواده‌ی کلمه | decide → decision → decisive | خیر |
| Collocation | make a decision | خیر |
| یادداشت من | (کاربر خودش می‌نویسه) | خیر |

### روند تولید محتوا
1. شما **اسم فصل + لیست لغت‌ها** رو می‌فرستید.
2. من معنی، مثال، نکته و تمرین‌ها رو می‌نویسم (محتوای اختصاصی، نه کپی از کتاب).
3. فصل به اپ اضافه می‌شه و شما امتحانش می‌کنید.
4. تأیید می‌کنید یا تغییر می‌خواید.

## ۴. ساختار ناوبری (Navigation)

نوار پایین صفحه با ۴ بخش:

| آیکون | بخش | کار |
|---|---|---|
| خانه | **امروز** | نقطه‌ی شروع روزانه |
| نقشه | **مسیر** | سطح‌ها و فصل‌ها |
| کارت | **لغت‌ها** | همه‌ی لغت‌ها، جستجو، لغت‌های سخت |
| نمودار | **پیشرفت** | آمار و درصدها |

تنظیمات (و Export/Import) از آیکون چرخ‌دنده‌ی بالای صفحه‌ی «امروز» باز می‌شه.

## ۵. اولین اجرا (Onboarding)

۳ صفحه‌ی کوتاه و قابل رد شدن:

1. **خوش‌آمد:** یک جمله درباره‌ی اینکه اپ چطوری کار می‌کنه.
2. **هدف روزانه:** چند لغت جدید در روز؟
   - ۵ (سبک) · **۱۰ (پیشنهادی)** · ۱۵ · ۲۰
3. **یادآوری:** ساعت تمرین روزانه + درخواست مجوز Notification.
   - پیش‌فرض: ساعت ۲۰:۰۰
4. **گزینه‌ی جانبی:** «پشتیبان دارم» ← رفتن مستقیم به Import

## ۶. صفحه‌ی اصلی: «امروز»

مهم‌ترین صفحه‌ی اپ. باید در یک نگاه بگه **امروز چی کار کنم**.

```
┌────────────────────────────────┐
│ سلام!                    ⚙️   │
│ 🔥 ۱۲ روز پشت سر هم            │
├────────────────────────────────┤
│  هدف امروز                     │
│  ████████░░░░  ۶ از ۱۰ لغت     │
├────────────────────────────────┤
│ ┌────────────────────────────┐ │
│ │ مرور امروز                 │ │
│ │ ۱۸ لغت منتظر مرورن         │ │
│ │ حدود ۴ دقیقه               │ │
│ │          [ شروع مرور ]     │ │
│ └────────────────────────────┘ │
│ ┌────────────────────────────┐ │
│ │ ادامه‌ی درس                │ │
│ │ Elementary · فصل ۳: Food   │ │
│ │ ███████░░░ آموزش: ۱۴ از ۲۰  │ │
│ │          [ ادامه ]         │ │
│ └────────────────────────────┘ │
├────────────────────────────────┤
│ لغت‌های سخت (۷)        مرور ›  │
├────────────────────────────────┤
│ 🏠امروز  🗺مسیر  🃏لغت‌ها  📊پیشرفت │
└────────────────────────────────┘
```

### قوانین صفحه‌ی امروز
- **اولویت با مرور است.** اگه مرور داشته باشید، کارت «مرور امروز» اول نشون داده می‌شه و دکمه‌ی اصلی صفحه‌ست.
- وقتی مرور تموم شد، کارتش به «✓ مرور امروز انجام شد» تبدیل می‌شه و «ادامه‌ی درس» دکمه‌ی اصلی می‌شه.
- وقتی هدف روزانه کامل شد: پیام تبریک + امکان «ادامه بده» (اجباری نیست).
- اگه بیش از ۱۴ روز از آخرین پشتیبان گذشته باشه، یک بنر کوچک «از پیشرفتت پشتیبان بگیر» نمایش داده می‌شه.

### حالت‌های خاص
| حالت | نمایش |
|---|---|
| روز اول | فقط «شروع فصل ۱» |
| مرور زیاد جمع شده (مثلاً بعد از چند روز غیبت) | «۸۵ مرور داری. امروز ۳۰ تاش رو انجام بده» (سقف روزانه) |
| همه‌ی فصل‌های باز تموم شده | «آزمون سطح Elementary آماده‌ست» |

## ۷. صفحه‌ی «مسیر»: سطح‌ها و فصل‌ها

### نمای سطح‌ها
بالای صفحه یک انتخابگر افقی سطح‌ها:

```
[ Elementary ✓ ] [ Pre-int ● ] [ Intermediate 🔒 ] [ ... ]
```

### نمای فصل‌ها (لیست عمودی)

```
┌────────────────────────────────┐
│ Pre-intermediate               │
│ ██████░░░░ تسلط سطح: ۵۸٪       │
├────────────────────────────────┤
│ ✓ فصل ۱  Family       ★★★  ۹۲٪ │
│ ✓ فصل ۲  Jobs         ★★☆  ۷۴٪ │
│ ● فصل ۳  Food     در حال یادگیری│
│ 🔒 فصل ۴  Travel               │
│ 🔒 فصل ۵  Weather              │
│ ...                            │
│ 🔒 آزمون سطح                    │
└────────────────────────────────┘
```

### وضعیت‌های فصل

| وضعیت | آیکون | معنی |
|---|---|---|
| قفل | 🔒 | فصل قبلی هنوز قبول نشده |
| باز | ○ | می‌شه شروعش کرد |
| در حال یادگیری | ● | آموزش یا تمرین نیمه‌کاره |
| قبول‌شده | ✓ | آزمون فصل با ۷۰٪ یا بیشتر قبول شده |
| نیاز به مرور | ⚠ | تسلط فصل زیر ۵۰٪ افتاده (کلمه‌ها داره یادش می‌ره) |

### دو عدد روی هر فصل (مهم)
1. **ستاره‌ها:** بهترین نمره‌ی آزمون فصل. **ثابت می‌مونه.**
2. **درصد تسلط:** چقدر از لغت‌های فصل الان واقعاً توی حافظه‌ست. **با مرور بالا می‌ره و با فراموشی پایین میاد.**

این تفکیک مهمه: ستاره نشون می‌ده «یه بار یاد گرفتم» و تسلط نشون می‌ده «الان هم یادمه».

## ۸. صفحه‌ی جزئیات فصل

با زدن روی یک فصل:

```
┌────────────────────────────────┐
│ ‹  فصل ۱ · Family              │
│ ۲۲ لغت · تسلط ۹۲٪ · ★★★        │
├────────────────────────────────┤
│ ① آموزش          ✓ کامل       │
│ ② تمرین معنی      ✓ ۹۰٪        │
│ ③ وصل کردن        ✓ ۱۰۰٪       │
│ ④ جای خالی        ✓ ۸۰٪        │
│ ⑤ شنیداری         ✓ ۸۵٪        │
│ ⑥ آزمون فصل       ✓ ۹۵٪        │
├────────────────────────────────┤
│ لیست لغت‌های این فصل        ›   │
│ [ تکرار آزمون ] [ مرور فصل ]   │
└────────────────────────────────┘
```

- مرحله‌ها به‌ترتیب باز می‌شن، ولی **تکرار هر مرحله همیشه آزاده.**
- لیست لغت‌ها جلوی هر کلمه یک نشانگر وضعیت داره (بخش ۱۲).

## ۹. فرایند یادگیری یک فصل

```
آموزش ← تمرین معنی ← وصل کردن ← جای خالی ← شنیداری ← آزمون فصل ← مرور روزانه
```

### ① آموزش (کارت‌های لغت)
- هر کارت: کلمه، دکمه‌ی تلفظ، معنی فارسی، جمله‌ی مثال، نکته (در صورت وجود).
- اگه فصل تصویر یا شجره‌نامه داره (مثل Family)، پایین کارت نمایش داده می‌شه.
- ورق زدن با Swipe یا دکمه‌های قبلی و بعدی.
- دکمه‌ی «⭐ سخته» برای علامت زدن کلمه.
- **قانون هدف روزانه:** اگه فصل ۲۰ لغت داشته باشه و هدف روزانه ۱۰ باشه، آموزش در دو جلسه‌ی ۱۰ تایی انجام می‌شه.

### ② تا ⑤: تمرین‌ها

| تمرین | توضیح | سختی |
|---|---|---|
| تمرین معنی | کلمه‌ی انگلیسی ← انتخاب معنی از ۴ گزینه | ★ |
| معنی برعکس | معنی فارسی ← انتخاب کلمه‌ی انگلیسی | ★ |
| وصل کردن | ۴ تا ۵ جفت کلمه و معنی | ★★ |
| جای خالی | جمله با جای خالی ← تایپ کلمه | ★★★ |
| شنیداری | پخش تلفظ ← تایپ کلمه | ★★★ |

#### قوانین مشترک تمرین‌ها
- بعد از هر جواب، بازخورد فوری میاد: سبز (درست) یا قرمز (غلط + نمایش جواب درست).
- سؤال‌های غلط **آخر همون تمرین دوباره پرسیده می‌شن.**
- **قبول شدن تمرین:** ۷۰٪ یا بیشتر. زیر ۷۰٪ ← «دوباره تلاش کن» (مرحله‌ی بعد باز نمی‌شه).
- در تایپ: حروف بزرگ و کوچک و فاصله‌ی اضافه نادیده گرفته می‌شه. یک غلط املایی کوچک ← «تقریباً درسته» (نیم امتیاز + نمایش املای درست).
- نوار پیشرفت بالای صفحه + دکمه‌ی خروج (با پرسیدن «پیشرفت این تمرین ذخیره نمی‌شه، مطمئنی؟»).

### ⑥ آزمون فصل
- ترکیبی از همه‌ی نوع‌های تمرین، **بدون نمایش جواب درست تا آخر آزمون.**
- همه‌ی لغت‌های فصل حداقل یک بار پرسیده می‌شن.
- بدون محدودیت زمانی.

| نمره | نتیجه |
|---|---|
| زیر ۷۰٪ | قبول نشده. لغت‌های اشتباه نشون داده می‌شن + «مرور و تلاش دوباره» |
| ۷۰ تا ۸۴٪ | قبول ★ |
| ۸۵ تا ۹۴٪ | قبول ★★ |
| ۹۵٪ و بالاتر | قبول ★★★ |

با قبول شدن آزمون:
- فصل بعدی باز می‌شه.
- همه‌ی لغت‌های فصل وارد **مرور روزانه** می‌شن.

### صفحه‌ی نتیجه

```
┌────────────────────────────────┐
│           ★★☆                  │
│       نمره‌ی شما: ۸۸٪           │
│      ۱۹ از ۲۲ درست              │
├────────────────────────────────┤
│ لغت‌هایی که اشتباه زدی:         │
│  • niece    برادرزاده (دختر)    │
│  • nephew   برادرزاده (پسر)     │
│  • cousin   دخترخاله...         │
├────────────────────────────────┤
│ 🔓 فصل ۲ باز شد                 │
│ [ رفتن به فصل ۲ ]  [ صفحه‌ی اصلی ]│
└────────────────────────────────┘
```

## ۱۰. آزمون سطح

- وقتی **همه‌ی فصل‌های یک سطح قبول شده باشن** باز می‌شه.
- ۴۰ سؤال از همه‌ی فصل‌های سطح، با تأکید بیشتر روی لغت‌های ضعیف.
- **قبولی: ۷۵٪** ← سطح بعدی باز می‌شه + نشان (Badge) سطح.
- **میان‌بُر:** اگه فکر می‌کنید یک سطح رو بلدید، می‌تونید آزمون سطح رو **بدون گذروندن فصل‌ها** بدید. با قبولی همه‌ی فصل‌هاش «قبول‌شده» علامت می‌خورن. (برای کسی که Elementary رو بلده و نمی‌خواد از صفر شروع کنه.)

## ۱۱. مرور روزانه (Spaced Repetition)

### الگوریتم
**FSRS**: همون الگوریتم جدید Anki. بر اساس سابقه‌ی هر لغت، زمان مرور بعدی رو حساب می‌کنه.

### جلسه‌ی مرور
1. یک لغت نشون داده می‌شه (به شکل یکی از تمرین‌ها، به‌صورت تصادفی).
2. شما جواب می‌دید.
3. اگه درست بود، سؤال می‌شه چقدر سخت بود:

| دکمه | معنی | اثر |
|---|---|---|
| یادم نبود | غلط جواب دادم | امروز دوباره میاد |
| سخت | به زحمت یادم اومد | فاصله‌ی کم |
| خوب | یادم بود | فاصله‌ی معمولی |
| آسون | خیلی راحت | فاصله‌ی زیاد |

### قوانین
- **سقف مرور روزانه:** ۱۰۰ (قابل تغییر در تنظیمات).
- بعد از چند روز غیبت، مرورها به‌جای اینکه یک‌جا بیان، **در چند روز پخش می‌شن.**
- لغت‌های فصل‌های مختلف قاطی هم پرسیده می‌شن.

---

## ۱۲. وضعیت لغت‌ها و محاسبه‌ی درصدها

### ۵ وضعیت هر لغت

| وضعیت | رنگ | شرط |
|---|---|---|
| جدید | خاکستری | هنوز آموزش داده نشده |
| در حال یادگیری | آبی | آموزش دیده، هنوز وارد مرور با فاصله‌ی بلند نشده |
| مرور | زرد | فاصله‌ی مرور بین ۱ تا ۲۱ روز |
| مسلط | سبز | فاصله‌ی مرور ۲۱ روز یا بیشتر |
| سخت | قرمز | ۳ بار یا بیشتر اشتباه شده (یا کاربر ⭐ زده) |

### فرمول‌ها

```
تسلط فصل  = (مسلط × ۱ + مرور × ۰.۶ + در حال یادگیری × ۰.۳) ÷ کل لغت‌های فصل
تسلط سطح  = میانگین تسلط فصل‌های اون سطح
پیشرفت کل = تعداد لغت‌های غیر از «جدید» ÷ کل لغت‌ها
```

---

## ۱۳. صفحه‌ی «لغت‌ها»

- لیست همه‌ی لغت‌هایی که آموزش دیدید.
- **جستجو** (انگلیسی یا فارسی).
- **فیلترها:** وضعیت · سطح · فصل · لغت‌های سخت · ⭐ علامت‌دار.
- با زدن روی هر لغت: کارت کامل لغت + تاریخ مرور بعدی + «یادداشت من» (برای ترفند حافظه).
- دکمه‌ی «مرور لغت‌های سخت» یک جلسه‌ی مرور اضافه فقط با لغت‌های قرمز می‌سازه.

```
└────────────────────────────────┘
```

### نشان‌ها (Badges): ساده و کم
- اولین فصل قبول‌شده
- Streak هفت، سی و صد روزه
- ۱۰۰، ۵۰۰ و ۱۰۰۰ لغت مسلط
- قبولی هر سطح

## ۱۵. نوتیفیکیشن‌ها

### اصل طراحی
**کم، به‌موقع و مفید.** نوتیفیکیشن مزاحم باعث می‌شه کاربر کلش رو خاموش کنه.

### انواع

| نوع | زمان | متن نمونه | شرط ارسال |
|---|---|---|---|
| یادآوری روزانه | ساعت انتخابی کاربر (پیش‌فرض ۲۰:۰۰) | «۱۸ لغت منتظر مرورن، حدود ۴ دقیقه وقت می‌بره» | فقط اگه امروز تمرین نکرده باشه |
| هشدار Streak | ساعت ۲۲:۰۰ | «🔥 Streak دوازده روزه‌ت رو از دست نده!» | Streak بیشتر از ۳ روز + امروز تمرین نکرده |
| پشتیبان | یکشنبه‌ها ساعت ۱۲:۰۰ | «از پیشرفتت پشتیبان بگیر تا اگه گوشی عوض شد چیزی از دست نره» | بیشتر از ۱۴ روز از آخرین Export گذشته |
| برگشت | ۳ روز بعد از آخرین استفاده | «لغت‌هات دارن یادت می‌رن، ۵ دقیقه مرور؟» | فقط یک بار، بعد دیگه تکرار نمی‌شه |

### قوانین
- **حداکثر ۲ نوتیفیکیشن در روز.**
- اگه امروز تمرین کرده باشید، هیچ یادآوری‌ای نمیاد.
- هر نوع جداگانه از تنظیمات قابل خاموش کردنه.
- با زدن روی نوتیفیکیشن، مستقیم مرور امروز باز می‌شه.
- اندروید ۱۳ به بالا: مجوز نوتیفیکیشن در Onboarding گرفته می‌شه. اگه رد بشه، اپ بدون نوتیفیکیشن کامل کار می‌کنه.

## ۱۶. پشتیبان‌گیری (Export / Import)

### Export
1. تنظیمات ← «پشتیبان‌گیری» ← «ساخت فایل پشتیبان»
2. فایل ساخته می‌شه: `vocab-backup-2026-10-31.json`
3. پنجره‌ی اشتراک‌گذاری اندروید باز می‌شه: ذخیره در Files یا Google Drive، ارسال به تلگرام یا ایمیل خودتون و ...

### چی داخل فایل هست

| داده | شامل |
|---|---|
| پیشرفت | فصل‌ها و مرحله‌های قبول‌شده، نمره‌ها، ستاره‌ها |
| مرور | وضعیت و زمان‌بندی FSRS تک‌تک لغت‌ها |
| آمار | Streak، تقویم فعالیت، نشان‌ها |
| شخصی | یادداشت‌ها، ⭐ علامت‌ها |
| تنظیمات | هدف روزانه، ساعت یادآوری |

محتوای درس‌ها داخل فایل نیست چون همراه خود اپه، پس فایل کوچیکه (چند ده کیلوبایت).

### Import
1. تنظیمات ← «بازیابی از پشتیبان» ← انتخاب فایل
2. **پیش‌نمایش قبل از جایگزینی:**
   > این پشتیبان مال ۳۱ اکتبر ۲۰۲۶ است · ۳۴۲ لغت · Pre-intermediate فصل ۳ · Streak دوازده روزه
   > **پیشرفت فعلی این گوشی جایگزین می‌شه.** [ بازیابی ] [ انصراف ]
3. قبل از جایگزینی، از وضعیت فعلی یک پشتیبان خودکار گرفته می‌شه (برای وقتی که اشتباهی Import کردید).
4. فایل خراب یا نامعتبر ← پیام خطا، بدون اینکه چیزی تغییر کنه.

### لایه‌ی دوم
Android Auto Backup هم فعال می‌شه. اگه روی گوشی جدید با همون حساب گوگل وارد بشید، ممکنه پیشرفت خودکار برگرده. ولی چون همیشه قابل اعتماد نیست، **Export دستی روش اصلیه.**
